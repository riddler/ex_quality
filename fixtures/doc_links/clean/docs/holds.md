# Holds

A hold waits for a copy at the patron's branch. When the copy comes in it
becomes a [loan](loans.md), and the [overview](../README.md#branch-catalogue)
says how a patron finds one. The rules are in [the branch guide](branches.md).
The `m:` and `e:` forms are ExDoc's own: [loans](e:branch:loans.md).

Code is not a link: `[hold](missing.md)`, nor is this:

```markdown
[copy](missing.md)
```

An asset is published as it is: ![A branch](assets/branch.svg).
